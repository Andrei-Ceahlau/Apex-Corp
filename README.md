# Apex Corp Website

Website-ul companiei Apex Corp construit cu React, TypeScript și Tailwind CSS.

## Cerințe

- Node.js (versiunea 18 sau mai nouă)
- npm (versiunea 9 sau mai nouă)

## Instalare

1. Clonează repository-ul:
```bash
git clone https://github.com/Andrei-Ceahlau/Apex-Corp.git
cd Apex-Corp
```

2. Instalează dependențele:
```bash
npm install
```

3. Pornește serverul de dezvoltare:
```bash
npm run dev
```

Aplicația va fi disponibilă la adresa: [http://localhost:5173](http://localhost:5173)

## Comenzi disponibile

- `npm run dev` - Pornește serverul de dezvoltare
- `npm run build` - Construiește aplicația pentru producție
- `npm run preview` - Previzualizează build-ul de producție
- `npm run lint` - Rulează verificarea de cod

## Structura proiectului

- `src/` - Codul sursă al aplicației
  - `components/` - Componentele React
  - `context/` - Context-uri React
  - `types/` - Definiții TypeScript
- `public/` - Fișiere statice
- `index.html` - Punctul de intrare al aplicației

## Tehnologii utilizate

- React
- TypeScript
- Tailwind CSS
- Vite
- ESLint
